# 冻结计划

测试规则：baseline、现有 intent-check、Proactive Advisor v1.1。每种条件运行三种同源上下文任务，各一次，共九次，先不修改规则。

共同题目及 A/B 回答来自先前已保存原文；比较意图开场与总结末句是依据回忆重构，并未找回失败轮原文。另两题为改题控制和后续推进的合成任务。每题标准在 cases.json 中，执行模型只收到 conversation.md 与本题末尾消息，不收到评分标准。

目标是先检查是否能在 Codex 中重现 Work 的偏题。不要求出现失败，也不据九次试验宣布普遍有效。全部正确时保留结果，记录当前测试难度不足或环境差异，不为了造出优势调整输入。评分是维护者人工检查，非独立盲评。日志证实读取与行为效果分别记录，自动调用与 Work 复测未覆盖。
