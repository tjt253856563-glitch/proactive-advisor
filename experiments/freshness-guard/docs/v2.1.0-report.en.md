# Freshness Guard 2.1.0 upgrade report

[中文](v2.1.0-report.md) · [Project overview](../README.en.md)

Date: October 22, 2026 (Asia/Singapore). The existing private plugin was updated. All 14 stored files were read back consistently; its identity and private audience were preserved.

## Completed work

- Fixed reproduced checker defects: invalid company/kind/status field types caused crashes; whitespace-only limitations and future publication dates were accepted.
- Strengthened date, declared-origin deduplication, boolean, checked-channel-list and text-field gates. Future announced events remain allowed; future events cannot be labeled effective.
- Implemented the previous evaluation plan as runnable tooling: 16 frozen cases, randomized three-condition order, raw-response import, blinded copies, independently reviewed gold binding, paired differences, intervals, elapsed time and extra-action summaries.
- Missing/unscored data are not passes. Unobservable traces remain null. Inconsistent models/plugin versions, stale gold, modified responses, reused sessions and pairs outside the declared time window cannot count as complete comparisons.

## Executed validation

- Existing synthetic structural regression: 43/43 passed.
- New regression methods: 14/14 passed, including 500 field-type mutations and 15 targeted invalid-input checks.
- Historical evidence from October 19: accepted by the new structural checker; its factual claims were not rechecked against current sources.
- YAML/JSON parsing, archive integrity and metadata-preservation checks passed. All 14 plugin files matched after read-back.
- Empty real experiment: 48 planned trials pending, zero real Chat outputs, null rates, and exit code 2 (incomplete).

See the [test records](../recorded/2026-10-22/). Synthetic responses used by tests existed only in temporary test directories and were not imported into the real experiment.

## Outstanding work and observed blocker

Actual three-condition ordinary-Chat comparisons, independently scored accuracy and long-term automatic invocation remain unverified. The available browser inventory contained only the in-app browser and MCP Apps. A ChatGPT page appeared in inventory, but attempts to create/read page state timed out twice. No usable interactive session was obtained, no evaluation question was submitted, and no Codex answer was relabeled as an ordinary-Chat trial.

This iteration delivered checker fixes, evaluation tooling and a private plugin update. It did not establish improved Chat reliability or resolve every recorded problem. Actual responses, contemporaneous gold evidence and independent judgments remain necessary.

The checker still cannot determine whether source text really supports a claim, or authenticate declared independence, logs or account observations. Removing condition metadata only attempts blinding: response text may reveal the condition. Repeated trials of the same case are not independent samples. Older live-cases files contain questions to investigate, not current ground truth.
