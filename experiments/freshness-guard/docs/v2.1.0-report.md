## 尚未完成与具体阻碍

普通Chat实际三条件对照、独立准确率及长期自动触发率仍未验证。当前浏览器库存只提供应用内浏览器和MCP Apps；尝试打开chatgpt.com后能列出页面，但创建/读取页面状态两次超时，未取得会话交互能力。没有发送评测问题，没有消耗真实评测试次，也没有把Codex回答改称Chat对照。

因此本轮完成的是代码、评测工具和私人插件升级，不代表“Chat可靠性已经改善”或原项目所有问题均已解决。缺乏独立评分者、真实会话输出和同期金标准时，必须继续保持待验证。

其他已知边界：脚本仍不能判断原文是否真正支持断言，也不能认证人工填写的独立性、日志或权限观察。盲评副本移除运行条件，但回答内容可能泄露条件；重复同题的试次也并非独立样本。包中保留的旧live-cases是待核问题，不是当前真值。
