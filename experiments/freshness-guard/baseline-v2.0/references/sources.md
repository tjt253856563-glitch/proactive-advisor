|---|---|---|---|
| OpenAI | openai.com/news/、原始发布公告、developers.openai.com 模型页 | help.openai.com、产品发布日志；区分 Chat / Work / Codex / API | openai.com/our-structure/、公司公告 |

这些是发现入口，不是固定事实数据库；页面迁移时用限定域名检索，不猜新 URL。检查链接实际最终域名，防止相似域名与跳转。域名只能帮助辨识，仍须检查正文是谁发布、是否确为官方口径。

发布新闻支持当时的事件；当前模型列表支持当前列出的型号；两者不能互代。原始模型卡可核验身份，不能证明该账户权限。官方页面无日期时记录未公开；当前页面也可能缓存，须陈述工具返回的覆盖限制。
